# 절차적 스테이지 생성 시스템 (Procedural Stage Generation)

## 1. 개요

각 액트(봄/여름/가을/겨울) 내 30개 스테이지 중, **보스(3개) + 휴식/이벤트(3개) + 튜토리얼(Act 1한정 3개)를 제외한 나머지 일반 스테이지**(Act 1: 21개, Act 2~4: 24개)의 내부 콘텐츠(레이아웃, 기믹, 몬스터)가 스테이지 진입 시점에 절차적으로 생성됩니다.

### 핵심 원칙
1. **테마 일관성** — 해당 액트의 계절 비주얼·기믹 풀을 따름
2. **난이도 곡선 준수** — 서막 → 전개 → 클라이맥스의 3구간 스케일링 유지
3. **핵심 이벤트 보장** — 중간보스(10, 20), 최종보스(30) 등 고정 이정표 유지

### 노드맵 연동 규칙
- 액트맵의 **노드 배치 및 분기 구조는 고정**입니다.
- 각 노드에 배정되는 **스테이지 내부 콘텐츠만 절차적으로 생성**됩니다.
- 노드 유형(일반 전투, 엘리트 전투, 이벤트, 휴식, 히든)은 `Game_Design_Spec.md`의 노드 유형 비율을 따릅니다.

## 2. 스테이지 레이아웃 모듈 시스템

핀볼 보드 레이아웃을 **세그먼트(Segment)** 단위로 분할하여 런타임에 조합합니다.

### 세그먼트 구조
```
┌─────────────────────────────┐
│     [상단 세그먼트]          │  ← 보스/엘리트 배치 영역
│  범퍼 구역, 보스 약점 영역    │
├─────────────────────────────┤
│     [중단 세그먼트 A~C]      │  ← 기믹/레일/함정 배치 영역
│  랜덤 조합 대상 (2~4개)      │  ← 스크롤 깊이 결정
├─────────────────────────────┤
│     [하단 세그먼트]          │  ← 플리퍼 영역 (고정)
│  닫힌 바닥 + 플리퍼 소환 영역 │  ← 2026-05-13: 데드존 제거, 외벽 닫힌 통
└─────────────────────────────┘
```

### 세그먼트 풀
- **상단 세그먼트 풀**: 테마별 8~12개의 프리셋 (보스 배치 위치, 범퍼 구성 변형)
- **중단 세그먼트 풀**: 테마별 15~20개의 프리셋 (기믹 슬롯, 레일 경로, 함정 배치)
- **하단 세그먼트**: 고정 구조 (플리퍼 존 + 닫힌 바닥) _(2026-05-13 데드존 제거: 낙사 라인 폐지, 외벽 닫힌 통)_

### 조합 규칙

| 난이도 구간 | 중단 세그먼트 수 | 스크롤 깊이 | 비고 |
|---|---|---|---|
| 서막 (1~9) | 2개 | 짧음 | 학습 구간, 단순한 구조 |
| 전개 (11~19) | 3개 | 보통 | 기믹 복잡도 증가 |
| 클라이맥스 (21~29) | 3~4개 | 김 | 최대 복잡도 |

### 세그먼트 연결 규칙
- 인접한 중단 세그먼트 간에는 반드시 **1개 이상의 연결 통로**(레일 또는 개방 공간)가 존재해야 합니다.
- 막힌 구조(Dead End)는 반드시 보상(아이템/범퍼)이 배치된 경우에만 허용됩니다.
- 각 중단 세그먼트에는 **기믹 슬롯 2~4개**가 존재하며, 여기에 기믹이 배치됩니다.

## 3. 난이도 예산 시스템 (Difficulty Budget)

각 스테이지는 **난이도 예산(Budget)** 값을 가지며, 이 예산을 소비하여 기믹·몬스터·환경 효과를 배치합니다.
플레이어의 **권장 레벨** 기준으로 밸런싱됩니다. _(레벨 시스템 상세는 `Game_Design_Spec.md` 섹션 7 참조)_

### 액트별 권장 레벨 및 난이도 배율

| 액트 | 순서 | 권장 레벨 | 난이도 배율 | 클리어 시 예상 레벨 |
|---|---|---|---|---|
| 🌸 Act 1 (봄) | 1번째 | Lv.1~25 | ×1.0 | ~Lv.25 |
| 🌊 Act 2 (여름) | 2번째 | Lv.25~50 | ×1.8 | ~Lv.50 |
| 🍁 Act 3 (가을) | 3번째 | Lv.50~72 | ×2.5 | ~Lv.72 |
| ❄️ Act 4 (겨울) | 4번째 | Lv.72~90 | ×3.5 | ~Lv.88~92 |

> **밸런스 목표**: 일반 플레이어가 **레벨 90 전후**에서 Act 4 최종 보스(겨울 여왕)를 클리어할 수 있도록 설계합니다.

### 난이도 예산 공식
```
BaseBudget = 100 + (StageIndex * 20)
ActMultiplier = {Act1: 1.0, Act2: 1.8, Act3: 2.5, Act4: 3.5}
FinalBudget = BaseBudget * ActMultiplier + Random(-10%, +10%)
```

#### 예시 (Act 1: 봄, 권장 Lv.1~25)
| 스테이지 | BaseBudget | 최종 예산 (±10%) |
|---|---|---|
| 1 | 120 | 108 ~ 132 |
| 9 | 280 | 252 ~ 308 |
| 15 | 400 | 360 ~ 440 |
| 29 | 680 | 612 ~ 748 |

#### 예시 (Act 4: 겨울, 권장 Lv.72~90, ×3.5 배율)
| 스테이지 | BaseBudget | 최종 예산 (±10%) |
|---|---|---|
| 1 | 120 | 378 ~ 462 |
| 29 | 680 | 2,142 ~ 2,618 |

### 예산 소비 테이블

| 요소 | 예산 비용 | 비고 |
|---|---|---|
| **공통 기믹 (버프)** | 5~15 | 도움이 되는 기믹은 낮은 비용 |
| **공통 기믹 (디버프/시련)** | 20~40 | 방해 기믹은 높은 비용 |
| **테마 전용 기믹 (버프)** | 10~20 | 테마 풍미 가산 |
| **테마 전용 기믹 (디버프/시련)** | 25~50 | 강력한 시련 |
| **일반 몬스터 웨이브** | 15~30 | 웨이브 수·HP에 비례 |
| **엘리트 몬스터** | 40~60 | 높은 예산, 높은 보상 |
| **환경 효과 (폭풍, 안개 등)** | 10~25 | 분위기 + 난이도 |
| **보상 기믹 (보물, 시간 구슬)** | -10~-20 | 음수 비용: 예산 환급 (난이도 완화) |

### 핵심 밸런스 규칙
- 각 스테이지의 기믹 중 **최소 1개는 반드시 버프/보상 기믹**이어야 합니다 (리스크-리워드 밸런스).
- **시련 기믹 3개 이상 중첩 시**, 보상 기믹 1개가 자동 추가됩니다 (플레이어 구제).
- 남은 예산이 음수가 되면 추가 기믹 배치를 중단합니다.

## 4. 기믹 배치 규칙

### 기믹 풀 구성
```
스테이지 기믹 풀 = 공통 베이스 20종 + 해당 액트 전용 15종 = 총 35종
```

### 배치 알고리즘
1. **스테이지 전체 기믹 수 결정** (난이도 구간 기반):
   - 서막 (1~9): 스테이지 전체에 **1~2개** 기믹 배치
   - 전개 (11~19): 스테이지 전체에 **3~4개** 기믹 배치
   - 클라이맥스 (21~29): 스테이지 전체에 **4~5개** 기믹 배치
   > **세그먼트 슬롯과의 관계**: 각 중단 세그먼트에는 2~4개의 기믹 슬롯이 존재하지만, 모든 슬롯이 채워지는 것은 아닙니다. 위 기믹 수가 **스테이지 전체 합계**이며, 시스템이 적절한 슬롯에 분배합니다.

2. **예산 내 기믹 랜덤 추출** (가중치 적용):
   - 해당 액트 전용 기믹에 가중치 2배 부여
   - 이전 스테이지에서 등장한 기믹은 가중치 0.5배 감소 (중복 방지)

3. **충돌 방지 규칙 적용**:
   - ❌ `중력 역전` + `얼음 바닥` 동시 출현 금지 (물리 충돌)
   - ❌ `어둠의 장막` + `짙은 안개` 동시 출현 금지 (시야 이중 차단)
   - ❌ `플리퍼 침묵` + `빙결 바닥` 동시 출현 금지 (조작 완전 봉쇄)
   - ❌ `무거워진 공` + `중력 역전` 동시 출현 금지 (물리 모순)
   - ❌ `반전 거울` + `투명 플리퍼` 동시 출현 금지 (조작 불가)
   - ❌ `동상 래그` + `플리퍼 침묵` 동시 출현 금지 (입력 완전 마비)

4. **시너지 조합 가중치 증가**:
   - ✅ `독장판` + `정화의 불꽃` → 해제 수단이 있으므로 보상적 난이도
   - ✅ `소용돌이` + `가속 레일` → 속도 시너지로 흥미로운 궤적 생성
   - ✅ `시간의 모래시계` + `해적 폭탄` → 보스 정지 중 폭탄 타격 기회
   - ✅ `자성 블록` + `히든 범퍼` → 파밍 시너지

5. **테마 비율 보장**: 배치된 기믹 중 **최소 40%는 해당 액트 전용 기믹**에서 선택

## 5. 몬스터 웨이브 절차 생성

### 스테이지별 권장 레벨 공식

각 스테이지의 **권장 레벨**은 아래 공식으로 계산됩니다. 이 값은 오버레벨링 XP 페널티의 기준이 됩니다.

```
RecommendedLevel = ActStartLevel + floor(StageIndex * (ActEndLevel - ActStartLevel) / 30)
```

| 액트 | ActStartLevel | ActEndLevel | 스테이지 1 권장 | 스테이지 15 권장 | 스테이지 30 권장 |
|---|---|---|---|---|---|
| Act 1 (봄) | 1 | 25 | Lv.1 | Lv.13 | Lv.25 |
| Act 2 (여름) | 25 | 50 | Lv.25 | Lv.37 | Lv.50 |
| Act 3 (가을) | 50 | 72 | Lv.50 | Lv.61 | Lv.72 |
| Act 4 (겨울) | 72 | 90 | Lv.72 | Lv.81 | Lv.90 |

### 기본 스탯 참조

> 몬스터 기본 스탯은 `Game_Design_Spec.md` 섹션 9에 정의된 값을 사용합니다:
> **BaseHP=100, BaseATK=5, BaseDEF=0%, BaseXP=12**

### 웨이브 구성 공식
```
WaveCount = floor(StageIndex / 5) + 1    // 결과: 1~7 웨이브
MonsterHP  = BaseHP  * ActMultiplier * (1 + StageIndex * 0.05)
MonsterATK = BaseATK * ActMultiplier * (1 + StageIndex * 0.03)
```

### 웨이브 구성 패턴
각 웨이브는 아래 3가지 패턴 중 하나가 랜덤 선택됩니다:

| 패턴 | 설명 | 적 구성 |
|---|---|---|
| **물량 러시** | 약한 적이 대량 출현 | 소형 몬스터 8~12마리, HP 0.5배 |
| **정예 소수** | 강한 적이 소수 출현 | 중형 몬스터 3~5마리, HP 1.5배 |
| **보스 호위** | 엘리트 1마리 + 졸개 | 엘리트 1 + 소형 4~6마리 |

### 엘리트 몬스터 스폰 확률
```
EliteChance = min(0.5, 0.05 * StageIndex)   // 5%에서 시작, 최대 50%
```
- 엘리트 출현 시 해당 웨이브의 일반 몬스터 수가 **50% 감소**
- 엘리트는 `Game_Design_Spec.md`의 보상 체계(코어 조각, 룬 드랍) 유지

### 테마별 몬스터 비주얼 풀
- 🌸 봄: 슬라임, 독버섯, 요정 전사, 거미, 식충식물 졸개
- 🌊 여름: 해적 졸병, 해파리, 게 전사, 상어, 문어
- 🍁 가을: 톱니 골렘, 유령, 가면 광대, 기계 인형, 호박 워리어
- ❄️ 겨울: 얼음 골렘, 눈사람 병사, 서리 정령, 늑대, 빙하 기사

## 6. 고정 이정표 (Milestone) 시스템

절차 생성에서 **반드시 고정되는 스테이지**:

| 스테이지 번호 | 유형 | 내용 |
|---|---|---|
| **1~3** | 튜토리얼 | Act 1 한정 강제 튜토리얼 (기존 기획 유지). Act 2~4에서는 일반 서막 스테이지로 절차 생성 |
| **5, 15, 25** | 휴식/이벤트 | 70% 확률로 휴식 노드, 30% 확률로 이벤트 노드 배정 |
| **10** | 중간 보스 ① | 각 액트의 기존 기획된 중간보스 ①이 반드시 출현 (고정 레이아웃) |
| **20** | 중간 보스 ② | 각 액트의 기존 기획된 중간보스 ②가 반드시 출현 (고정 레이아웃) |
| **30** | 최종 보스 | 각 액트의 3페이즈 최종보스가 반드시 출현 (고정 레이아웃) |

### 휴식 노드 내용 (70% 확률)
- **제한 시간 회복**: 다음 스테이지 진입 시 제한 시간 **+20초** 보너스 (시간 회복 상한에 포함되지 않음).
- **마나 충전**: 마나 게이지 **50%** 회복.
- **소매품 구매**: 용병단 창고 소모품을 골드로 구매 가능 (스테이지 중 사용 가능).

### 이벤트 노드 내용 (30% 확률)
아래 유형 중 1개가 랜덤 선택됩니다:

| 이벤트 | 설명 | 보상/위험 |
|---|---|---|
| **수상한 여행자** | NPC가 난이도 관련 2택 1 선택지 제시 | "다음 스테이지 몬스터 HP -20%" vs "다음 스테이지 보상 2배" |
| **보물 방** | 전투 없이 보물상자 3개를 열어 드랍 획득 | 골드, 코어 조각, 타로카드 중 랜덤 |
| **신비한 제단** | 제한 시간 30초 소모 대신 스킬 포인트 +1 획득 | 리스크-리워드 선택 |
| **방랑자의 도박** | 카지노 범퍼와 유사한 도박 이벤트 | 대박 버프 or 맞으면 난이도 증가 |

### 절차 생성 대상 스테이지
나머지 **4, 6~9, 11~14, 16~19, 21~24, 26~29** (Act 1: 총 **21개**, Act 2~4: 1~3 포함 총 **24개**)가 절차 생성 대상입니다.

### 노드 유형 비율과 고정 이정표의 관계

`Game_Design_Spec.md`에서 정의한 노드 유형 비율(일반 전투 70%, 엘리트 10%, 이벤트 10%, 휴식 5%, 히든 5%)은 **30개 노드 전체에 대한 목표 비율**입니다. 고정 이정표가 먼저 배치된 후, 나머지 절차 생성 노드가 목표 비율에 맞춰 유형이 결정됩니다.

| 유형 | 목표 수 (30개 중) | 고정 이정표 선점 | 나머지 절차 생성 배분 |
|---|---|---|---|
| 일반 전투 | ~21개 (70%) | 0개 | 21~24개 (절차 생성 대상 전부가 기본) |
| 엘리트 전투 | ~3개 (10%) | 0개 | 절차 생성 노드 중 3개를 엘리트로 교체 |
| 보스 전투 | 3개 (고정) | 3개 (10, 20, 30) | — (고정) |
| 이벤트 | ~3개 (10%) | ~1개 (5, 15, 25 중 30%) | 나머지 1~2개 추가 배치 |
| 휴식 | ~2개 (5%) | ~2개 (5, 15, 25 중 70%) | 부족 시 1개 추가 |
| 히든 | ~1~2개 (5%) | 0개 | 절차 생성 노드 중 1~2개를 히든으로 교체 |

> **히든 노드 출현 조건**: 기본 5% 확률로 절차 생성 노드가 히든 노드로 변환됩니다. 열기구 3단계 개조 시 확률 +15%. 히든 노드는 액트맵에서 흐릿한 점으로 표시되며, 인접 노드를 클리어해야 실체화됩니다.

## 7. 스테이지 특성(Modifier) 시스템

기존 기믹과는 별도로, 스테이지 전체에 적용되는 **글로벌 특성(Modifier)**을 랜덤 부여합니다.

### 적용 규칙
- 서막 (1~9): 특성 **없음** (기본 학습 구간 보호)
- 전개 (11~19): 특성 **0~1개** (50% 확률로 1개 적용)
- 클라이맥스 (21~29): 특성 **1~2개** (100% 확률로 1개, 30% 확률로 추가 1개)

## 8. 돌연변이 스테이지 (Mutation Stage)

극히 드물게(5% 확률) 절차 생성 중 **돌연변이**가 발생하여 특수한 스테이지가 생성됩니다.

### 돌연변이 유형

| 돌연변이 유형 | 설명 | 출현 조건 |
|---|---|---|
| **테마 침식** | 다른 액트의 기믹이 1~2개 침범 (예: 봄 스테이지에 겨울 `얼음 바닥` 등장) | 전개 구간 이후 |
| **거울 세계** | 맵 레이아웃이 좌우 반전되어 모든 공간 감각이 뒤바뀜 | 어디서든 |
| **미니어처** | 맵이 극도로 축소되어 공이 빠르게 벽을 튕김, 반응 속도 체크 | 클라이맥스 구간 |
| **타임 러시** | 제한 시간 60초, 몬스터 HP 50% 감소, 보상 3배 | 어디서든 |
| **보스 러시** | 이전에 처치한 중간보스가 약화(HP 50%) 상태로 재등장 | 클라이맥스 구간 |

### 돌연변이 보상
- 클리어 시 **골드 2배** 지급
- **희귀 룬 드랍 확률** 15% 증가
- 액트맵에서 돌연변이 노드는 **특수 아이콘(⚠️)**으로 표시 (진입 전 인지 가능)
- 돌연변이 스테이지를 회피하고 다른 분기로 진행할 수 있음 (선택의 자유)

## 9. 시드 기반 재현 시스템

모든 절차 생성은 **시드(Seed)** 값에 기반합니다.

### 시드 생성 규칙

| 상황 | 시드 공식 | 효과 |
|---|---|---|
| **최초 진입** | `PlayerUID + 현재 날짜 해시` | 같은 날 같은 플레이어는 동일한 맵 배치 |
| **재도전** | `기존 시드 + 시도 횟수` | 재도전할 때마다 다른 레이아웃 생성 |
| **일일 도전** | `날짜 해시 (전체 플레이어 공통)` | 주점 의뢰 시스템과 연동 |

### 일일 도전 시드 활용
- 주점(Tavern)의 **일일 의뢰**와 연동하여, 전체 유저가 동일한 시드의 스테이지에서 경쟁합니다.
- 예시: _"오늘의 도전: 봄 Act 스테이지 15를 시드 #20260510으로 90초 내 클리어하라"_
- 전체 유저가 **동일한 레이아웃·기믹·몬스터 배치**에서 타임어택 → 랭킹 시스템 연동 가능
- 일일 도전 시드는 **매일 자정(UTC+9)에 갱신**

## 10. 스테이지 생성 흐름 요약

```
[1] 스테이지 진입
       ↓
[2] 고정 이정표 여부 확인 (10, 20, 30번 → 기존 보스 레이아웃 로드)
       ↓ (일반 스테이지)
[3] 시드 생성 (플레이어 UID + 날짜 + 스테이지 인덱스)
       ↓
[4] 난이도 예산 계산 (BaseBudget × ActMultiplier ± 10%)
       ↓
[5] 레이아웃 세그먼트 조합 (난이도 구간에 따른 중단 세그먼트 수 결정)
       ↓
[6] 기믹 풀에서 추출 (예산 소비, 충돌 규칙 검증, 테마 비율 보장)
       ↓
[7] 몬스터 웨이브 생성 (웨이브 수, 패턴, 엘리트 확률)
       ↓
[8] 돌연변이 판정 (5% 확률)
       ↓
[9] 스테이지 특성(Modifier) 적용 (전개/클라이맥스 구간)
       ↓
[10] 최종 스테이지 데이터 확정 → 플레이 시작
```
