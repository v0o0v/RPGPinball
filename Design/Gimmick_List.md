# RPG 핀볼 로그라이크 기믹 80선 리스트

어느 액트를 가든 기본적으로 등장하는 **공통 베이스 기믹 20선**과, 각 계절의 테마를 극대화하는 **계절 전용 기믹 각 15선**입니다. 각 기믹은 Unity 구현용 **스펙 표**를 포함합니다.

---

## 0. 표준 정의

본 문서의 모든 기믹은 아래 통일 표 형식을 따릅니다. `Active_Skill_Judgment.md`의 형식을 차용합니다.

### 표 컬럼 의미

| 항목 | 의미 |
|---|---|
| **분류** | 버프 / 디버프 / 시련 / 보상 / 환경 — 난이도 예산 부호 결정 |
| **판정 형태** | 원형 / 직사각형 / 반원 / 직선 / 전역 / 공-부착형 / 자기버프 / 영역(맵) 등 |
| **판정 범위 (Unit)** | 반경 R, 또는 너비 W × 높이 H. (1 Unit ≈ 1m. 플레이필드 9.0×12.0 Unit) |
| **트리거** | 공 접촉 / 시간 주기 / 스테이지 진입 / 외부 이벤트 등 |
| **효과** | 게임플레이 결과 (수치화). 데미지·시간·확률·배율 명시 |
| **지속시간 (s)** | 1회 효과의 유지 시간. `즉발`/`영구(스테이지)`/`주기`도 표기 |
| **쿨다운 (s)** | 동일 기믹의 재발동 대기 시간 (해당 시) |
| **블로킹 가능** | 공/플리퍼로 효과 무력화·간섭 가능 여부 |
| **저항력 적용** | 도감 `resistLevel`에 따라 페널티 감쇠 여부 (`Data_Schema.md` §7) |
| **난이도 예산** | 절차 생성 시 소비 예산 (음수 = 보상). `Procedural_Stage_Gen.md` §3 표 |
| **배치 가능 영역** | 상단/중단/하단 세그먼트 중 어디에 배치 가능한지 |

### 단위 및 기준

- **1 Unit ≈ 1m** (Unity 기본). 공 반지름 0.25, 플레이필드 9.0×12.0/세그먼트.
- 시간 단위: 초(s).
- 데미지: `공격력의 N%` 또는 절대 HP. 보스 HP 기준값은 `Game_Design_Spec.md` §9 참조.
- 시간 페널티: 5~10초 단위. 보스 강제 reset 기본 -15초(`Constants.BossForcedTimePenalty`)가 상한 기준. _(2026-05-13 데드존 제거: 구 "낙사 -10초 상한" → "보스 강제 reset -15초 상한"으로 재정의.)_
- **⚠️ 2026-05-13 데드존 메커닉 제거 반영**: 본 문서의 가시 함정(G-19) · 소멸 타일(G-18) · 중력 반전(G-44) 등 "낙사" 또는 "데드존" 표현을 포함하는 기믹은, 외벽 닫힌 통 구조에서 **시간 페널티 발행 + 공 강제 reset(`BallController.ForceReset()`) 트리거**로 재구성된다. 본 구현은 M8 인계.
- 도감 저항력: 동일 기믹 사망 누적으로 자동 감쇠 (`Data_Schema.md` §7, 0~40%).
- 난이도 예산 부호: 버프/보상은 음수(예산 환급), 디버프/시련은 양수.

### 연계 문서

- 충돌 방지 규칙 / 시너지 가중치: `Procedural_Stage_Gen.md` §4
- 도감 저항력 누적 공식: `Data_Schema.md` §7
- 기믹 저항력 시스템 메타: `Game_Design_Spec.md` §3 (점성술사)
- 물리 상수 일관성: `Physics_Parameters.md`

## 카테고리 요약 (예산 합계 검증)

절차 생성 시 한 스테이지의 기믹 조합이 `FinalBudget` 범위(`Procedural_Stage_Gen.md` §3) 안에 들도록 균형을 맞추는 데 사용합니다.

| 분류 | 개수 | 평균 예산 | 비고 |
|---|---|---|---|
| 보상 / 보상-우세 | 23개 | -13 (음수, 예산 환급) | 마나 제단·아이템 류 |
| 시련 (디버프) | 28개 | 30 (양수, 예산 소비) | 침묵·둔화·시야 차단 류 |
| 환경 (양면) | 21개 | 18 | 텔레포트·소용돌이·룰렛 류 |
| 보스 전용 | 8개 | 35 | 보스 룸에만 배치 |
| 스테이지 modifier (전역) | 10개 | 28 | 세그먼트 슬롯 무관, 스테이지 1개 한정 |

> **검증 가이드**: Act 1 스테이지 1(예산 108~132)에서는 대표적으로 `보상 1개(-12) + 시련 1개(+25) + 환경 1개(+15)` ≈ +28 소비, 잔여 예산은 몬스터 웨이브에 사용. Act 4 클라이맥스(예산 2,142~2,618)는 시련 4~5개 + 보상 1~2개 + 엘리트 + 모디파이어 1~2개로 채웁니다.
