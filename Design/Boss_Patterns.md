# 보스 행동 패턴 정의서 (Boss Patterns)

각 보스의 행동 패턴, 탄막 설계, 페이즈 전환 조건, 대응 전략을 Unity 구현 수준으로 정의한 문서입니다.
보스 기본 스탯은 `Game_Design_Spec.md` 섹션 9, 데미지 연산은 `Damage_Formula.md`를 참조하세요.

---

## 공통 규칙

### 보스 행동 사이클
```
[대기(Idle)] → [패턴 선택(AI)] → [예고(Telegraph)] → [실행(Execute)] → [후딜레이(Recovery)] → [대기]
```
- **예고(Telegraph)**: 모든 공격 패턴은 실행 전 **0.5~1.5초**의 시각적 예고가 반드시 존재 (공정한 회피 기회 보장)
- **후딜레이(Recovery)**: 공격 후 **1.0~2.0초** 동안 보스가 무방비 상태 (공격 기회 창)

### 탄막 공통 사양
| 항목 | 소형 탄막 | 대형 탄막 | 특수 탄막 |
|---|---|---|---|
| 반지름 | 0.15 Unit | 0.4 Unit | 0.6 Unit |
| 이동 속도 | 8.0 U/s | 6.0 U/s | 패턴별 상이 |
| 블로킹 가능 | ✅ | ✅ | ⚠️ 패턴별 상이 |
| 데드존 관통 페널티 | -5초 | -8초 | -10초 |

### 분노 모드 (공통)
- HP **30% 이하** 진입 시 모든 보스에 적용
- 공격 속도 **1.3배**, 탄막 밀도 **1.5배**, 패턴 간 대기 시간 **0.7배**

## 🌸 Act 1: 봄 (Spring)

---

### 보스 1-1: 거대 식충식물 (스테이지 10)

> **컨셉**: 화면 중앙 고정형 보스. 덩굴 채찍과 포자 탄막으로 공 경로를 방해. 약점(꽃봉오리)은 상단에 위치.

| 항목 | 수치 |
|---|---|
| HP | 4,500 |
| DEF | 20% (약점 타격 시 DEF 무시) |
| 위치 | 상단 세그먼트 중앙 고정 |
| 약점 | 꽃봉오리 (본체 상단, 반지름 0.8 Unit) |
| 제한 시간 | 180초 |

#### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 | 빈도 |
|---|---|---|---|---|---|
| P1 | 덩굴 채찍 | 0.8초 (덩굴 진동) | 좌/우 중 한쪽으로 덩굴을 휘둘러 수평 스윕. 공 접촉 시 강제 넉백 | 1.5초 | 30% |
| P2 | 포자 산탄 | 1.0초 (꽃봉오리 팽창) | 하단 방향 부채꼴 60°로 소형 탄막 5발 발사 | 2.0초 | 35% |
| P3 | 덩굴 장벽 | 1.2초 (바닥에서 덩굴 그림자) | 중단 세그먼트에 덩굴 2개 솟아올려 통로 차단 (5초 후 소멸) | 1.0초 | 20% |
| P4 | 꽃가루 안개 | 0.5초 (포자 비산) | 약점 주변 반경 2 Unit 시야 차단 (3초 유지) | 1.5초 | 15% |

#### 분노 모드 추가
- P2 포자 산탄이 **8발**로 증가, 각도 90°로 확대
- 덩굴 장벽이 **3개**로 증가

#### 공략 포인트
- 덩굴 채찍 후딜레이 1.5초가 핵심 공격 타이밍
- 약점(꽃봉오리) 타격 시 DEF 무시 → 플리퍼로 상단 조준 필수

### 보스 1-2: 타락한 요정 (스테이지 20)

> **컨셉**: 고속 이동형 보스. 환각 버섯과 가짜 공으로 교란. Phase 3에서 분신 분열.

| 항목 | 수치 |
|---|---|
| HP | 5,800 |
| DEF | 15% |
| 이동 속도 | 12.0 U/s (텔레포트 포함) |
| 히트박스 | 반지름 0.6 Unit (소형) |
| 제한 시간 | 180초 |

#### Phase 1 (HP 100%~60%)

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 순간이동 난사 | 0.5초 (잔상) | 랜덤 위치로 텔레포트 후 소형 탄막 3발 직선 발사 | 1.5초 |
| P2 | 환각 버섯 소환 | 1.0초 (마법진) | 필드에 환각 버섯 2개 배치. 공 접촉 시 가짜 공 3개 생성 (5초) | 2.0초 |
| P3 | 요정 먼지 | 0.8초 (반짝임) | 하단 방향 나선형 소형 탄막 8발 | 1.5초 |

#### Phase 2 (HP 60%~30%) — 가짜 공 대량 생성
- P2의 환각 버섯이 **3개**로 증가, 가짜 공이 **5개**로 증가
- 신규 패턴 **P4 거울 복제**: 보스가 0.5초간 정지 → 잔상 2개를 남기고 이동. 잔상은 타격 판정 없음 (페이크)

#### Phase 3 (HP 30% 이하) — 분신 분열
- 본체가 **분신 3체**로 분열 (총 HP을 3등분하여 분배)
- 각 분신은 독립적으로 Phase 1 패턴을 사용
- **진짜 본체 구별법**: 이동 시 미세한 그림자 존재 (다른 분신은 그림자 없음)
- 1체 격파 시 나머지 분신의 공격 속도 **1.2배** 증가

### 보스 1-3: 세계수 수호정령 (스테이지 30) — 최종 보스

> **컨셉**: 3페이즈 대형 보스. 뿌리 장벽 → 꽃가루 침묵 → 광합성 재생의 단계적 위협.

| 항목 | 수치 |
|---|---|
| HP | 12,000 |
| DEF | Phase 1: 25% → Phase 2: 20% → Phase 3: 15% |
| 크기 | 상단 세그먼트 전체 점유 (너비 7 Unit) |
| 제한 시간 | 180초 |

#### Phase 1: 뿌리 수호 (HP 100%~60%)

| # | 패턴명 | 상세 |
|---|---|---|
| P1 | 뿌리 장벽 | 중단 세그먼트에 뿌리 3개 생성 (각 HP 500). 뿌리 파괴 시에만 본체 노출 |
| P2 | 열매 폭탄 투하 | 1.2초 예고 후 낙하 지점 표시 → 대형 열매 3개 투하. 착지 시 반경 1.5U 폭발 |
| P3 | 덩굴 올가미 | 공이 3초 이상 같은 세그먼트에 머물면 덩굴이 솟아 공 속도 50% 감소 (2초) |

- **전환 조건**: 뿌리 3개 모두 파괴 + HP 60% 이하

#### Phase 2: 꽃가루 폭풍 (HP 60%~30%)

| # | 패턴명 | 상세 |
|---|---|---|
| P4 | 꽃가루 침묵 | **3초 간격**으로 꽃가루 폭풍 발생 → 1.5초간 플리퍼 소환 불가 |
| P5 | 꽃잎 회전 탄막 | 본체 중심으로 소형 탄막 12발이 시계 방향 회전하며 나선 확산 (10초 주기) |
| P6 | 씨앗 폭격 | 하단 방향으로 소형 탄막 6발 직선 연사 (0.3초 간격) |

- **핵심**: 침묵 타이밍과 탄막을 동시에 관리해야 함

#### Phase 3: 광합성 재생 (HP 30% 이하)

| # | 패턴명 | 상세 |
|---|---|---|
| P7 | 광합성 재생 | **초당 HP 1% 회복** (120 HP/초). DPS 레이스 돌입 |
| P8 | 최후의 뿌리 | 뿌리 2개 재생 (각 HP 300). 본체 방어용 |
| P9 | 전방위 꽃잎 | 360도 소형 탄막 16발 동시 발사 (5초 주기) |

- **승리 조건**: 재생량(120/초)을 초과하는 DPS 유지
- **공략**: 분노의 일격(HP 30% 이하 추가 데미지) + 처형자의 룬(×2) 활용

## 🌊 Act 2: 여름 (Summer)

---

### 보스 2-1: 거대 무장 게 (스테이지 10)

> **컨셉**: 등껍질(상단) 무적, 배(하단)만 공격 가능. 집게로 플리퍼 파괴 특수 공격.

| 항목 | 수치 |
|---|---|
| HP | 8,100 |
| DEF | 등껍질: **무적** / 배(약점): **0%** |
| 이동 | 좌우 왕복 (속도 4.0 U/s), 주기적 방향 전환 |
| 제한 시간 | 180초 |

#### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 집게 강타 | 1.0초 (집게 들어올림) | 한쪽 집게를 내려찍어 해당 영역 플리퍼 즉시 소멸 + 2초간 해당 구역 소환 금지 | 2.0초 |
| P2 | 거품 탄막 | 0.8초 (입에서 거품) | 하단 방향 대형 거품 탄막 3발 (느린 속도 4.0 U/s, 넓은 판정) | 1.5초 |
| P3 | 등껍질 돌진 | 1.5초 (몸 웅크림) | 좌→우 또는 우→좌 고속 돌진 (8.0 U/s). 경로상 공 강제 넉백 | 2.5초 |
| P4 | 배 노출 | — (자동) | 돌진(P3) 직후 뒤집어져 배 노출 **3초간** → 핵심 공격 타이밍 | 자동 복귀 |

#### 분노 모드 추가
- 배 노출 시간 3초 → **2초**로 단축
- 집게 강타가 **양쪽 동시**로 변경
- 거품 탄막 5발로 증가

#### 공략 포인트
- P3 돌진 후 P4 배 노출이 유일한 공격 기회
- 집게 강타 예고 시 해당 구역 회피 필수

### 보스 2-2: 유령 해적선장 (스테이지 20)

> **컨셉**: 대포 연사 + 유령 수하 소환. 럼주 음용 시 일시 무적.

| 항목 | 수치 |
|---|---|
| HP | 10,400 |
| DEF | 20% |
| 위치 | 상단 좌/우 이동 (속도 5.0 U/s) |
| 제한 시간 | 180초 |

#### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 대포 연사 | 0.6초 (대포 조준선) | 하단 방향 소형 탄막 6발 연사 (0.2초 간격, 직선) | 1.5초 |
| P2 | 유령 수하 소환 | 1.0초 (해적기 펄럭) | 유령 졸개 3마리 소환 (각 HP 200). 하단 방향 이동하며 소형 탄막 발사 | 2.0초 |
| P3 | 포탄 투하 | 1.2초 (낙하 지점 표시) | 필드에 대형 포탄 2개 투하. 착지 시 반경 2.0U 폭발 + 화염 장판 3초 | 1.5초 |
| P4 | 럼주 무적 | 0.5초 (병 꺼냄) | 럼주 음용 → **4초간 완전 무적**. 무적 해제 직후 1.5초 경직 | 1.5초 (경직) |

#### 럼주 무적 메커니즘
- 무적 중 공 타격 → 데미지 0, 공은 물리 반사
- 무적 해제 직후 **1.5초 경직** → 핵심 딜 타이밍
- HP 50% 이하부터 럼주 사용 빈도 증가 (20% → 30%)
- 분노 모드 시 럼주 무적 시간 4초 → **3초**, 경직 1.5초 → **1.0초**

### 보스 2-3: 크라켄 (스테이지 30) — 최종 보스

> **컨셉**: 촉수 파괴 → 시야 차단 → 분노 재생의 3페이즈 대형 보스.

| 항목 | 수치 |
|---|---|
| HP | 21,600 (본체) |
| DEF | Phase 1: 30% → Phase 2: 25% → Phase 3: 20% |
| 촉수 | 8개 (각 HP 800, DEF 10%) |
| 제한 시간 | 180초 |

#### Phase 1: 촉수의 바다 (HP 100%~60%)

| # | 패턴명 | 상세 |
|---|---|---|
| P1 | 촉수 후려치기 | 촉수 1~2개가 화면 가장자리에서 수평 스윕. 0.8초 예고 (그림자 표시) |
| P2 | 먹물 탄막 | 본체(눈)에서 하단 방향 소형 탄막 8발 방사형 발사 (5초 주기) |
| P3 | 촉수 조이기 | 촉수 2개가 필드 좌우에서 조여 유효 플레이 폭 50% 축소 (4초간) |

- **본체(눈) 노출 조건**: 촉수 **4개 이상** 파괴 시 본체 히트박스 활성화
- 촉수 파괴 순서는 자유 (가까운 것부터 공략 가능)

#### Phase 2: 심해의 어둠 (HP 60%~30%)

| # | 패턴명 | 상세 |
|---|---|---|
| P4 | 먹물 분사 | 화면 **80% 시야 차단** (공 주변 반경 1.5U만 가시). 8초 유지, 12초 주기 |
| P5 | 소용돌이 | 필드 중앙에 소용돌이 생성 → 공 궤적을 나선형으로 왜곡 (6초간) |
| P6 | 촉수 창 | 하단에서 촉수 1개가 수직 돌출 (1.0초 예고). 공 접촉 시 강제 상방 넉백 |

- 먹물 중에도 보스 탄막은 계속 발사 → 소리와 진동으로 방향 판단 필요

#### Phase 3: 크라켄의 분노 (HP 30% 이하)

| # | 패턴명 | 상세 |
|---|---|---|
| P7 | 촉수 재생 | 파괴된 촉수 중 **2개 재생** (HP 400). 10초 주기 반복 |
| P8 | 레이저 빔 회전 | 본체(눈)에서 레이저 빔 발사 → 시계 방향 360° 회전 (4초 1회전). 플리퍼로 블로킹 불가 |
| P9 | 전방위 먹물 | 360도 대형 탄막 12발 동시 발사 + 먹물 시야 차단 동시 발동 |

- **레이저 빔 회피**: 점프 패드 활용 또는 빔 통과 시 회전 방향 반대로 공 이동
- **남은 촉수 수 비례 방어력**: 촉수 1개당 본체 DEF +3%. 촉수 전멸 시 DEF 20%, 촉수 4개 시 DEF 32%

## 🍁 Act 3: 가을 (Autumn)

---

### 보스 3-1: 미치광이 발명가 (스테이지 10)

> **컨셉**: 톱니바퀴 방패 + 터렛 소환형 보스. 반사 탄막과 십자포화로 압박.

| 항목 | 수치 |
|---|---|
| HP | 12,500 |
| DEF | 25% (방패 회전 시 +20% → 45%) |
| 위치 | 상단 좌우 이동 (속도 3.0 U/s) |
| 제한 시간 | 180초 |

#### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 톱니 방패 회전 | 0.6초 (기어 가속음) | 전면에 톱니바퀴 방패 전개. 공 접촉 시 반사 + 보스 DEF 45%로 상승. 4초간 유지 | 2.0초 |
| P2 | 터렛 설치 | 1.0초 (설계도 표시) | 필드에 터렛 1~2개 배치 (각 HP 400). 터렛은 2초 간격 소형 탄막 2발 발사 | 1.5초 |
| P3 | 반사 탄막 | 0.8초 (조준 레이저) | 소형 탄막 4발 발사 → 벽에 1회 반사 후에도 판정 유지 | 1.5초 |
| P4 | 기어 폭탄 | 1.2초 (낙하 표시) | 톱니바퀴 모양 폭탄 2개 투하. 착지 후 1.5초 뒤 폭발 (반경 1.5U) | 1.5초 |

#### 분노 모드 추가
- 터렛 동시 배치 **3개**로 증가, 터렛 발사 간격 1.5초로 단축
- 반사 탄막이 벽 **2회** 반사로 변경

### 보스 3-2: 호박머리 유령 (스테이지 20)

## 보스 연습 모드 연동

수련장의 **보스 연습 모드**와 본 문서의 패턴은 1:1로 대응됩니다.

| 기능 | 설명 |
|---|---|
