# RPG 핀볼 프로젝트 필수 준수 규칙 및 컨텍스트

## 1. 프로젝트 기획 문서 위치
현재 RPG 핀볼 게임의 모든 기획 스펙, 스킬 트리, 기믹 리스트는 다음 로컬 경로에 저장되어 있습니다:
* **경로**: `d:\unityProjects\git\RPG Pinball\Design\`
* **필수 행동**: 안티그래비티는 새로운 세션이 열렸을 때 개발이나 기획을 진행하기 전, 반드시 위 경로에 있는 `.md` 문서들을 읽고 게임의 맥락과 설정(무한 성장, 타임어택, 4계절 액트 등)을 완벽히 파악해야 합니다.

## 2. 문서 및 이미지 생성 규칙
1. **언어 (Language)**: 새롭게 작성되는 모든 기획 단계 문서와 UI/컨셉 이미지는 무조건 **한글(Korean)**을 기준으로 생성해야 합니다.
2. **문서 저장 경로**: 새로운 기획 문서(마크다운 파일)는 반드시 `d:\unityProjects\git\RPG Pinball\Design\` 폴더 안에 생성해야 합니다.
3. **이미지 저장 경로**: 생성된 목업 이미지나 컨셉 아트는 반드시 `d:\unityProjects\git\RPG Pinball\Design\image\` 폴더에 복사/저장해야 합니다.
4. **이미지 생성 스타일**: 앞으로 생성하는 모든 게임 UI 이미지는 기기 테두리나 손이 포함되지 않는 **순수한 전체화면 UI(Pure full-screen UI)**로 생성해야 합니다. 단, 스마트폰에 바로 적용할 수 있도록 **세로 화면 비율(Portrait)**과 모바일 UI 레이아웃(상하단 네비게이션, 터치 버튼 크기 등)에 완벽히 최적화된 형태로 디자인하세요.

## 3. 구현 및 개발 규칙 (Implementation)
1. **Unity MCP 활용**: 구현 및 테스트를 진행할 때는 항상 **Unity 에디터 공식 MCP**와 연동하여 C# 스크립트 실행, 씬 조작, 로그 확인 등을 적극적으로 활용해야 합니다. `mcpServers`에 등록된 `UnityEditor`를 통해 효율적인 개발을 진행합니다.
