# 액티브 스킬 판정 상세 스펙

`Skill_Tree_Formulas.md`에 정의된 모든 액티브(A) 및 전환형 액티브(A전환) 스킬의 **판정 범위(Unit)**, **히트 횟수**, **넉백 여부**를 Unity 구현용으로 정리한 문서입니다.

> **단위 기준**: 1 Unit ≈ 1m (Unity 기본 단위). 플레이필드 너비 9.0 Unit, 공 반지름 0.25 Unit. _(상세는 `Physics_Parameters.md` 참조)_

---

## 용어 정의

| 용어 | 설명 |
|---|---|
| **판정 범위** | 스킬 효과가 적용되는 공간적 영역 (반경, 전방 각도 등) |
| **히트 횟수** | 1회 발동 시 데미지가 적용되는 최대 횟수. `지속`은 매 틱마다 판정 |
| **넉백** | 적에게 물리적 밀어내기(Knockback) 힘을 가하는지 여부 |
| **Tick** | 지속형 스킬의 데미지 판정 주기 (기본 0.5초/틱) |

## 넉백 시스템 상세 규칙

### 넉백 면역 등급

| 등급 | 대상 | 일반 넉백 | 궁극기 넉백 |
|---|---|---|---|
| **없음** | 일반 몬스터 | ✅ 적용 | ✅ 적용 |
| **저항** | 엘리트 몬스터 | ✅ 적용 (거리 50% 감소) | ✅ 적용 (거리 75%) |
| **면역** | 중간 보스 | ❌ 면역 | ✅ 적용 (거리 30%) |
| **절대 면역** | 최종 보스 | ❌ 면역 | ⚠️ 궁극기만 적용 (거리 15%) |

### 넉백 물리 처리

```
KnockbackForce = BaseKnockbackDistance × (1 + 돌진력 보너스%) × ImmunityMultiplier
KnockbackDirection = normalize(적 위치 - 타격 지점) // 방사형
KnockbackDuration = 0.3초 // 넉백 경직 시간 (행동 불능)
```

- **돌진력(파괴 Tier 1-3)** 패시브가 넉백 거리를 증폭합니다.
- 넉백 중 적은 **행동 불능** 상태이며, 다른 적과 충돌 시 **연쇄 넉백** (충돌 넉백 거리의 30%)이 발생합니다.
- 벽에 부딪히는 넉백(월 슬램)은 추가 데미지 없음 (시각 이펙트만 연출).
