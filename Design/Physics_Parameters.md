# RPG 핀볼 물리 엔진 파라미터 종합표

Unity 2D 물리 엔진(Rigidbody2D + Collider2D) 기반으로 구현할 때 사용하는 핵심 상수 정의서입니다.
모든 단위는 Unity 단위(1 Unit ≈ 1미터)를 기준으로 합니다.

---

## 1. 월드 설정

| 파라미터 | 값 | 비고 |
|---|---|---|
| **중력 가속도** | (0, -15) m/s² | Unity 기본값(-9.81)보다 강함. 핀볼 특유의 빠른 낙하감 연출 |
| **물리 시뮬레이션 주기** | Fixed Timestep = 0.01초 (100Hz) | 고속 충돌 누락 방지를 위해 기본값(0.02)보다 높게 설정 |
| **최대 각속도** | 1000°/초 | 공의 과도한 회전 방지 |
| **Collision Detection Mode** | Continuous | 고속 이동 시 벽 관통 방지 |

## 3. 공(Ball) 파라미터

### 기본 파라미터

| 파라미터 | 값 | 비고 |
|---|---|---|
| **반지름** | 0.25 Unit | 화면 너비의 약 1/18 |
| **기본 질량** | 1.0 kg | 나무 공 기준, 재질에 따라 변동 |
| **기본 발사 속도** | 18.0 Unit/초 | 게임 시작 시 공 발사 속도 |
| **최대 이동 속도** | 40.0 Unit/초 | 하드캡. 가속 코어 등으로 상승해도 이 값 초과 불가 |
| **최소 이동 속도** | 2.0 Unit/초 | 이 미만으로 감속 시 자동 가속 보정 (정체 방지) |
| **Angular Drag** | 0.05 | 회전 감쇠 |
| **Linear Drag** | 0.0 | 공기 저항 없음 (핀볼 특성) |

### 재질별 물리 파라미터 (Physics Material 2D)

| 재질 | Mass | Bounciness | Friction | 비고 |
|---|---|---|---|---|
| 나무 공 | 1.0 | 0.9 | 0.2 | 기본값 |
| 강철 공 | 2.0 | 0.5 | 0.3 | 무겁고 묵직, 반발력 낮음 |
| 미스릴 공 | 1.2 | 0.7 | 0.25 | 균형형 |
| 화산암 공 | 1.5 | 0.6 | 0.35 | 약간 무겁고 마찰 높음 |

### 충돌 판정

| 상호작용 | 판정 방식 | 처리 |
|---|---|---|
| 공 ↔ 벽 | Collider2D (물리 반사) | Bounciness에 따른 자연 반사 |
| 공 ↔ 플리퍼 | Collider2D (물리 반사 + AddForce) | 플리퍼 회전 속도에 비례한 임펄스 추가 |
| 공 ↔ 범퍼 | Collider2D (물리 반사) | 고정 반발력으로 강하게 튕겨냄 |
| 공 ↔ 몬스터 | Trigger2D (관통) | 데미지 계산 후 공은 관통. 물리 반사 없음 |
| 공 ↔ 보스 | Trigger2D (관통) | 데미지 계산 후 공은 관통. 물리 반사 없음 |
| 공 ↔ 아이템 | Trigger2D (획득) | 접촉 즉시 획득 후 아이템 소멸 |
| 공 ↔ 탄막 | Trigger2D (피해) | 블로킹 실패 시 시간 페널티 적용 |
| ~~공 ↔ 데드존~~ | — | **2026-05-13 제거** — 외벽 닫힌 통 |

## 4. 플리퍼 파라미터

### 소환 타이밍

| 단계 | 시간 | 설명 |
|---|---|---|
| **소환 애니메이션** | 0.08초 | 터치 후 플리퍼가 나타나는 시간 (즉각적 느낌) |
| **히트 판정 시작** | 소환 즉시 (0초) | 애니메이션 도중에도 충돌 판정 활성 |
| **활성 유지 시간** | 0.5초 (기본) | 플리퍼가 화면에 머무는 시간 |
| **스윙 동작** | 활성 시작 ~ 0.15초 | 짧은 스윙 모션 (강한 반발력 구간) |
| **소멸 애니메이션** | 0.12초 | 페이드아웃으로 자연스럽게 사라짐 |
| **소환 쿨타임** | 1.5초 (기본) | 소멸 시점부터 다음 소환까지 대기 시간 |
| **쿨타임 하한** | 0.5초 (하드캡) | 모든 패시브 합산 시 최저값 |

### 물리 파라미터

| 파라미터 | 값 | 비고 |
|---|---|---|
| **기본 길이** | 2.5 Unit | 좌우 횡단면 길이 |
| **두께** | 0.3 Unit | 세로 두께 |
| **스윙 반발 임펄스** | 25.0 N | 스윙 구간(0~0.15초) 중 공 타격 시 추가 힘 |
| **정적 반발 임펄스** | 12.0 N | 스윙 후(0.15~0.5초) 정지 상태에서의 반발 힘 |
| **최대 타격 각도** | 75° | 플리퍼 중심에서 공이 튕겨나가는 최대 각도 |
| **터치 판정 반경** | 1.0 Unit | 터치 좌표 중심으로 플리퍼 생성 허용 범위 |
| **동시 소환 간격** | 최소 0.8 Unit | 2개 이상 소환 시 겹침 방지 최소 거리 |

### 소환 위치 제한

| 영역 | 소환 가능 여부 | 비고 |
|---|---|---|
| 플리퍼 영역 (하단 3 Unit) | ✅ 가능 | 기본 방어 구역 |
| 중단 세그먼트 | ✅ 가능 | 공격적 위치에서 소환 |
| 보스 영역 (상단) | ❌ 불가 | 보스 바로 앞에서의 무한 타격 방지 |
| 벽 내부 | ❌ 불가 | 벽과 겹치는 위치 자동 보정 |

## 5. 카메라 시스템

| 파라미터 | 값 | 비고 |
|---|---|---|
| **추적 대상** | 공 (Ball) | 멀티볼 시 가장 높이 있는 공 추적 |
| **추적 방식** | SmoothDamp | 부드러운 추적, 급격한 전환 방지 |
| **추적 속도** | smoothTime = 0.15초 | 공 이동 후 카메라가 따라가는 시간 |
| **수직 오프셋** | +2.0 Unit | 공보다 약간 위를 비추어 전방 시야 확보 |
| **수직 이동 범위** | 세그먼트 최하단 ~ 최상단 | 외벽 닫힌 통 내부에서만 이동 |
| **수평 고정** | 플레이필드 중앙 고정 | 좌우 스크롤 없음 (필드 너비 = 화면 너비) |
| **보스전 줌아웃** | Orthographic Size × 1.2 | 보스 등장 시 시야 확장 |
| **멀티볼 줌아웃** | 공 개수에 비례 (+0.1 per 공) | 모든 공이 시야에 들어오도록 자동 조정 |

| 파라미터 | 값 | 비고 |
|---|---|---|
| **기본 이동 속도** | 8.0 Unit/초 | 일반 몬스터 투사체 |
| **보스 탄막 속도** | 6.0 ~ 14.0 Unit/초 | 패턴에 따라 가변 |
| **탄막 크기 (소형)** | 반지름 0.15 Unit | 일반 탄막 |

| **블로킹 성공 시 쿨타임 감소** | -0.3초 | 기본 보상 (스킬로 증폭 가능) |
| **공 피격 시 페널티** | 제한 시간 -5초 | 플리퍼 블로킹 실패 시 (탄막 관통) |

## 7. 공 강제 리셋 (구 "낙사·리스폰" — 2026-05-13 개편)

> **데드존 메커닉 제거 (2026-05-13)** — 스테이지 외벽이 사방으로 닫힌 통이라 공이 절대 화면 밖으로 사라지지 않는다.
> 자연 낙사·낙사 페널티(-10/-20초) 시스템은 완전 삭제. 이 표는 **보스 강제 패턴**(서리거인 거대 주먹 강타, 겨울 여왕 절대 영도 등)이 공을 강제로 reset할 때만 적용된다.

| 파라미터 | 값 | 비고 |
|---|---|---|
| **강제 reset 트리거** | 보스 패턴이 `BallController.OnDead()` 호출 | 자연 낙사 없음. 보스가 명시적으로 호출할 때만 |
| **reset 위치** | 플레이필드 중앙 상단 | (0, 세그먼트 최상단 -2.0) |
| **reset 딜레이** | 1.0초 (기본) | 퀵 리커버리 스킬로 감소 가능 |
| **reset 무적 시간** | 1.5초 | reset 직후 탄막/함정 피해 면역 |
| **reset 발사 속도** | 18.0 Unit/초 (기본 발사 속도) | 아래 방향으로 자동 발사 |
| **보스 강제 reset 시간 페널티** | -15초 (`BossForcedTimePenalty`) | 보스 패턴이 `OnTimePenalty` 이벤트로 별도 발행 |
| **콤보 카운트** | 유지 | 자연 낙사 없음 → 콤보는 3초 무타격 시에만 자연 리셋 |
