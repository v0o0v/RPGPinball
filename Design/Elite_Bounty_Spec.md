# 현상금 엘리트 몬스터 상세 기획서 (Elite Bounty Specification)

주점(Tavern) 현상금 사냥 시스템에서 등장하는 엘리트 몬스터의 고유 능력, 행동 패턴, 스테이지 환경, 공략 전략을 Unity 구현 수준으로 정의한 문서입니다.

---

## 공통 규칙

### 현상금 스테이지 기본 사양

| 항목 | 수치 |
|---|---|
| 제한 시간 | **120초** (일반 스테이지 180초보다 짧음) |
| 스테이지 구조 | 전용 고정 레이아웃 (절차 생성 아님) |
| 일반 몬스터 | **없음** — 엘리트 1:1 결투 |
| 갱신 주기 | 주 단위, 4마리 중 3마리 무작위 선정 |
| 입장 조건 | 해당 엘리트가 소속된 액트의 최종 보스 처치 완료 |
| 재도전 | 동일 주간 내 무제한 재도전 가능 (보상은 첫 처치 시만) |

### 엘리트 행동 사이클
```
[대기(Idle)] → [고유 능력 발동] → [공격 패턴(2~3종)] → [약점 노출(Recovery)] → [대기]
```
- **약점 노출(Recovery)**: 모든 엘리트는 공격 루틴 종료 후 **2.0~3.0초**의 약점 노출 구간이 존재
- **분노 모드**: HP **25% 이하** 시 진입 (일반 보스 30%보다 낮음). 공격 속도 ×1.5, 약점 노출 시간 절반

### 확정 드랍 보상
| 보상 유형 | 수량 | 비고 |
|---|---|---|
| 고유 코어 조각 또는 전설 룬 | **1개 확정** | 엘리트별 고정 |
| 골드 | 2,000~5,000 | 엘리트별 차등 |
| 마나 결정 | 50~100 | 엘리트별 차등 |
| 경험치 | `BaseXP * ActMult * 10` | 일반 몬스터의 10배 |

## 🌸 폭풍의 정령 (Storm Elemental) — 봄 액트

> **컨셉**: 번개 분신과 극한 속도로 압도하는 순수 반응속도 체크 전투. 화면 전체를 누비며 뇌격을 퍼붓는다.

### 기본 스탯

| 항목 | 수치 |
|---|---|
| HP | 20,000 |
| DEF | 15% |
| 이동 속도 | **20.0 U/s** (게임 내 최고 속도 적) |
| 히트박스 | 반지름 0.5 Unit (소형) |
| 입장 조건 | Act 1 최종 보스(세계수 수호정령) 처치 |

### 고유 능력: 뇌신의 잔상 (Thunder Afterimage)

| 항목 | 상세 |
|---|---|
| 발동 조건 | 전투 시작 시 자동, 상시 유지 |
| 효과 | 이동 경로에 **0.5초 간격**으로 잔상(잔류 전기장)을 남김. 잔상은 **반경 0.8U**의 감전 필드를 형성하며, 공 접촉 시 **1초 속도 50% 감소 + 시간 -2초** |
| 잔상 지속 | 3초 후 소멸 |
| 분노 모드 | 잔상 간격 0.3초, 감전 필드 반경 1.2U |

### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 번개 분신 소환 | 0.5초 (전기 스파크) | 분신 3체 생성 (각 HP 0, 타격 판정 없음). 분신은 독립적으로 이동하며 잔상을 남김. 8초 후 소멸 | 1.0초 |
| P2 | 전방위 뇌격 | 1.0초 (전신 충전 빛) | 본체 중심 360° 번개 탄막 12발 방사 (속도 12 U/s). 블로킹 가능 | 2.5초 |
| P3 | 번개 돌진 | 0.3초 (잔상 수렴) | 공을 향해 직선 고속 돌진 (25 U/s). 경로에 폭 1.5U 번개 장판 3초 생성. 공 접촉 시 넉백 + 시간 -5초 | 3.0초 (벽에 충돌하여 경직) |

### 약점 노출 메커니즘
- **P3 번개 돌진 후** 벽에 충돌하면 **3.0초간 경직** → 핵심 공격 타이밍
- 분노 모드 시 경직 1.5초로 단축, 돌진 후 즉시 P2 연계

### 전용 스테이지 환경
- **봄 숲 투기장**: 중앙에 대형 나무 기둥 2개 (공 반사용 장애물 겸 엄폐물)
- **바람 기믹 상시 적용**: 5초마다 풍향 변경 (공 궤적 교란)

### 공략 포인트
- 잔상 필드를 피하며 공을 유도해야 하므로 **미스릴 공**(밸런스 좋음) 또는 **강철 공**(넉백 저항) 추천
- P3 돌진 경직이 유일한 대형 딜 타이밍 — 이때 콤보 스킬 집중
- 번개 분신은 공격 불가, 무시하고 본체 집중

## 🌊 심해 리바이어선 (Abyssal Leviathan) — 여름 액트

> **컨셉**: 압도적인 체력과 방어력의 극한 탱커. 잠수와 체력 흡수로 장기전을 강요하는 지구력 체크 전투.

### 기본 스탯

| 항목 | 수치 |
|---|---|
| HP | 40,000 |
| DEF | 40% |
| 크기 | 대형 (히트박스 반지름 2.0 Unit) |
| 이동 | 느린 수평 이동 (2.5 U/s) |
| 입장 조건 | Act 2 최종 보스(크라켄) 처치 |

### 고유 능력: 심연의 포식 (Abyssal Devour)

| 항목 | 상세 |
|---|---|
| 발동 조건 | 공이 리바이어선 본체에 타격할 때마다 |
| 효과 | 타격 데미지의 **10%를 HP로 회복** (리바이어선 → 자힐) |
| 회복 상한 | 1회 타격당 최대 200 HP 회복 |
| 분노 모드 | 흡수율 15%, 상한 300 HP |

### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 해일 밀어내기 | 1.5초 (해수면 상승 이펙트) | 화면 하단에서 상단 방향으로 해일 벽 발사. 공 접촉 시 강제로 상단 밀려남 + 1.5초 행동 불능. 해일 폭 전체 화면 너비 | 2.0초 |
| P2 | 잠수 | 0.8초 (물결 확산) | 수면 아래로 잠수 → **5초간 완전 무적**. 잠수 중 랜덤 위치에서 촉수 3개 솟아올라 공 넉백 (각 1.0초 예고) | 2.0초 (부상 직후) |
| P3 | 체력 흡수 촉수 | 1.2초 (바닥에서 촉수 그림자) | 공 현재 위치에 흡수 촉수 1개 생성 (HP 600). 공이 촉수에 접촉하면 **시간 -3초/초** 지속 흡수. 촉수를 파괴하면 해제 | 1.5초 |

### 약점 노출 메커니즘
- **P2 잠수 종료 후 부상 시** 배 부분(하단)이 **2.0초간 노출** → DEF **0%** 적용 (유일한 고효율 딜 타이밍)
- 분노 모드 시 부상 노출 1.0초로 단축, 부상 직후 P1 즉시 연계

### 전용 스테이지 환경
- **심해 투기장**: 화면 하단 30%가 수중 구역 (공 진입 시 속도 40% 감소, 마찰력 증가)
- **조류 기믹**: 10초마다 좌→우 또는 우→좌 해류 발생 (공에 2.0 U/s 횡력)

### 공략 포인트
- DEF 40% + 자힐 때문에 일반 타격으론 거의 HP가 줄지 않음 → **부상 시 DEF 0% 타이밍에 올인**
- 가시 플리퍼(DEF -10%) + 아머 크래시 스킬로 평시 방어력 깎기 병행
- 흡수 촉수는 즉시 파괴 우선 — 방치 시 시간 급감
- **화산암 공** 추천: 화상 도트가 잠수 중에도 적용됨

### 기본 스탯

| 항목 | 수치 |
|---|---|

| DEF | 10% |
| 이동 속도 | **20.0 U/s** (불규칙 지그재그) |
| 히트박스 | 반지름 0.4 Unit (극소형) |
| 입장 조건 | Act 3 최종 보스(태엽장치 드래곤) 처치 |

### 고유 능력: 탐욕의 도주 (Greed's Escape)

| 항목 | 상세 |
|---|---|
| 발동 조건 | 전투 시작 시 자동 |
| 효과 ① | **10초 카운트다운** 시작. 10초 내 최소 1회 타격하지 못하면 고블린 왕이 **즉시 도주**(전투 실패, 보상 없음) |
| 효과 ② | 첫 타격 성공 후에도 **60초 내 처치** 실패 시 도주 (제한 시간 120초와 별개의 도주 타이머) |
| 효과 ③ | 타격받을 때마다 **1초간 이동 속도 2배**(40 U/s)로 도주 가속 |
| 분노 모드 | 상시 이동 속도 25 U/s, 도주 타이머 45초로 단축 |

### 패턴 목록

| # | 패턴명 | 예고 | 실행 | 후딜레이 |
|---|---|---|---|---|
| P1 | 황금 폭탄 투척 | 0.3초 (폭탄 꺼냄) | 도주하며 뒤로 황금 폭탄 2개 투척. 2초 후 폭발 (반경 1.5U). 폭발 시 시간 -5초. 폭탄 파편은 골드 드랍(10골드×5개) | 없음 (도주 중 연속) |
| P2 | 연막 투척 | 0.5초 (연기탄 꺼냄) | 현재 위치에 연막 3초 생성 (반경 2.0U 시야 차단). 연막 안에서 방향 전환 (추적 교란) | 없음 |
| P3 | 보물 함정 | — (자동 배치) | 필드에 반짝이는 가짜 보물상자 1개 배치. 공 접촉 시 **2초간 공 동결** + 시간 -3초 | — |

### 약점 노출 메커니즘
- **벽 충돌 경직**: 고블린 왕이 도주 중 벽에 부딪히면 **1.5초 경직** (스턴) → 타격 기회
- **함정 역이용**: 가짜 보물상자를 고블린 왕이 밟으면 **2초 경직** (확률 15%, 자기 함정에 걸림)
- 분노 모드 시 벽 경직 0.8초로 단축

### 전용 스테이지 환경
- **가을 축제 미로**: 톱니바퀴 장벽이 좁은 통로를 형성. 고블린 왕의 도주 경로를 예측하기 용이
- **범퍼 다수 배치**: 공이 범퍼를 활용해 빠르게 방향 전환 가능
- **골드 보너스**: 이 스테이지에서 획득하는 모든 골드 **2배** 적용

### 공략 포인트
- 최우선: **10초 내 첫 타격** 필수. 충격파 플리퍼로 광역 판정 활용 추천
- 가속 코어(속도 증가)로 공 속도를 높여 추격력 확보
- 좁은 미로 통로에서 벽 경직을 유도하는 것이 핵심 전략
- 관성 돌파 + 콤보 스트라이크 빌드로 짧은 타격 기회에 최대 데미지

- **겨울 성벽 투기장**: 사각형 벽으로 둘러싸인 밀폐 공간. 벽 반사를 활용한 후방 우회 필수
- **빙판 바닥**: 필드 전체 마찰력 0.15 (매우 미끄러움)
- **레일 2개**: 좌측·우측 벽면을 타고 상단으로 올라가는 레일 (후방 진입 경로)

### 공략 포인트
- 정면 공격 무의미 → 벽 반사·레일을 이용한 **측면/후방 우회 타격**이 핵심
- P1 돌진 후 후방 노출 3초가 최대 딜 타이밍 — 처형자 룬(HP 30% 이하 ×2) 활용
- 빙결 오라 때문에 근접 체류 시간 관리 필수. 빠르게 들어가서 타격 후 빠져나오는 히트앤런
- **미스릴 공**(밸런스) + 연성 플리퍼(넓은 판정, 블로킹 용이) 추천
- 겨울 여왕 클리어 후 콘텐츠이므로 Lv.88~95 기준 밸런싱

## 밸런스 검증 시뮬레이션

### DPS 요구량 계산 (제한 시간 120초 기준)

| 엘리트 | 유효 HP | 필요 DPS | 비고 |
|---|---|---|---|
| 폭풍의 정령 | 20,000 × (1-0.15) ÷ 0.85 ≈ **20,000** | ~167/초 | DEF 낮음, 타격 기회 적음이 난이도 |
| 심해 리바이어선 | 40,000 + 자힐 ~8,000 ≈ **48,000** (유효) | ~400/초 (전체) | DEF 0% 타이밍 집중 시 실질 ~250 필요 |
| 황금 고블린 왕 | 15,000 × (1-0.10) ÷ 0.9 ≈ **15,000** | ~250/초 (60초 도주) | 히트 기회 극소, 실질 난이도 높음 |
| 서리 파수꾼 | 30,000 × (1-0.15) ÷ 0.85 ≈ **30,000** (후방) | ~250/초 | 포지셔닝 난이도가 핵심 |

> **Lv.90 파괴 빌드 DPS ~320** 기준, 모든 엘리트가 이론적으로 클리어 가능하나 기계적 실행력(타이밍·포지셔닝)이 클리어 여부를 결정합니다.
