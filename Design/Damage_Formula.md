# RPG 핀볼 데미지 공식 통합 문서

데미지 계산에 관여하는 모든 요소와 연산 순서를 한 곳에 정리한 문서입니다.
각 요소의 상세 스펙은 해당 문서를 참조하세요.

---

## 1. 데미지 연산 순서 (Damage Pipeline)

공이 적에게 타격할 때 아래 순서로 데미지가 계산됩니다.

```
[1] 기본 물리 데미지 계산
       ↓
[2] 스킬 트리 패시브 적용 (합연산 → 곱연산)
       ↓
[3] 코어 효과 적용
       ↓
[4] 재질 보너스 적용
       ↓
[5] 플리퍼 파생형 효과 적용
       ↓
[6] 룬 효과 적용 (조건부)
       ↓
[7] 타로카드 효과 적용 (해당 런 한정)
       ↓
[8] 크리티컬 판정
       ↓
[9] 적 방어력(DEF) / 마법 저항력(MRes) 감소
       ↓
[10] 최종 데미지 확정
```

---

## 2. 각 단계 상세

### [1] 기본 물리 데미지
```
BaseDamage = PlayerBaseDamage * (1 + PlayerLevel * 0.02)
```
- `PlayerBaseDamage`: 기본값 10 (Lv.1)
- Lv.90 기준: `10 * (1 + 90 * 0.02)` = **28**

### [2] 스킬 트리 패시브 (합연산 → 곱연산)
1. **합연산 그룹** (먼저 계산): 같은 종류의 합연산 효과를 모두 더함
   - 강철구 I: `+5% + (Lv * 1.5%)`
   - 콤보 스트라이크: `+2% + (Lv * 0.5%)` × 콤보 수
   - 묵직한 타격: `+15% + (Lv * 3%)`
   - 관성 돌파 I (속도 보너스): `1.2배 + (Lv * 0.03배)` ← 이것은 곱연산
2. **곱연산 그룹** (합연산 후 적용): 순서대로 곱함
   - 강철구 II: `× (1 + 3% + Lv * 1%)`
   - 관성 돌파 I: `× (1.2 + Lv * 0.03)` (속도 비례)
   - 플리퍼 스매시: `× (1.3 + Lv * 0.05)` (플리퍼 타격 직후 1회)
3. **곱연산 중첩 제한**: 동일 효과의 곱연산이 3개 이상이면 3번째부터 합연산으로 전환
   - "동일 효과"의 카테고리는 **최종 데미지 영향 단계 기준**으로 묶음 (예: 쿨타임 감소·공격력 증가·크리티컬 배율 등). 패시브 스킬·코어·룬·타로카드를 출처와 무관하게 합산.
   - 이 규칙은 **`Skill_Tree_Formulas.md` §곱연산 중첩 제한** 및 **`Tarot_Card_List.md` §밸런스 설계 원칙 2**와 동일 — 변경 시 세 문서를 함께 갱신할 것.

```
SkillDamage = BaseDamage * (1 + Σ합연산%) * Π곱연산배율
```

### [3] 코어 효과
| 코어 | 적용 방식 | 연산 유형 |
|---|---|---|
| 가속 코어 | 속도 10%당 물리 데미지 +5% | 합연산 |
| 분열 코어 | 복제 공 데미지 = 본체의 30% | 별도 개체 |
| 크로노 코어 | 데미지 미영향 (시간 회복) | — |

### [4] 재질 보너스
| 재질 | 효과 | 연산 유형 |
|---|---|---|
| 나무 공 | 보너스 없음 | — |
| 강철 공 | 장애물 돌파력 보너스 (데미지 무관) | — |
| 미스릴 공 | 마법(원소 스킬) 데미지 **×1.15** | 곱연산 (마법만) |
| 화산암 공 | 타격 시 화상 도트 (별도 데미지) | 별도 계산 |

### [5] 플리퍼 파생형 효과
| 파생형 | 효과 | 적용 시점 |
|---|---|---|
| 가시 플리퍼 | 적에게 DEF -10% 디버프 (5초) | 적 방어력 계산 시 |
| 연성 플리퍼 | 데미지 미영향 (판정 강화) | — |
| 충격파 플리퍼 | 광역 데미지 = 본체의 50% (마법) | 별도 계산 |

### [6] 룬 효과 (조건부 곱연산)
| 룬 | 조건 | 효과 | 연산 유형 |
|---|---|---|---|
| 처형자의 룬 | 보스 HP ≤ 30% | 스킬 데미지 **×2** | 곱연산 |
| 역경의 룬 | 남은 시간 ≤ 60초 | 스킬 데미지 **×1.5** | 곱연산 |
| 연쇄의 룬 | 20콤보 이상 | 마나 비용 -50% (데미지 무관) | — |
| 확산 룬 | 항상 | 3방향 분산, 각 데미지 50% | 별도 계산 |
| 관통 룬 | 항상 | 관통 시 데미지 -30% | 합연산 감소 |

### [7] 타로카드 효과
- "시작 시 마나 +20": 데미지 무관
- "보스 체력 5% 감소 상태로 시작": 보스 HP에 적용 (데미지 계산 외)
- "모든 재질 장점 동시 적용": 재질 보너스 단계에서 모든 재질 효과 합산

### [8] 크리티컬 판정
```
CritChance = BaseCritChance(5%) + 약점포착 보너스 + 스테이지특성 보너스
CritDamage = 1.5 + 가속의쾌감 보너스
If (Random < CritChance):
    Damage *= CritDamage
```

### [9] 적 방어력 적용
```
FinalDamage_Physical = Damage * (1 - EffectiveDEF%)
FinalDamage_Magic    = Damage * (1 - EffectiveMRes%)

EffectiveDEF  = BaseDEF - 아머크래시 감소량 - 가시플리퍼 디버프
EffectiveMRes = BaseMRes - 원소 상태이상 감소량
MRes = DEF * 0.5  (기본 마법 저항력 = 물리 방어력의 절반)
```

### [10] 최종 데미지
```
최종 데미지 = max(1, FinalDamage)  // 최소 1 데미지 보장
```

## 3. 데미지 시뮬레이션 예시

### 예시: Lv.90 파괴 빌드 vs 겨울 여왕 (Phase 3, DEF 20%)

| 단계 | 수치 | 누적 |
|---|---|---|
| 기본 데미지 (Lv.90) | 10 × 2.8 | 28 |
| 강철구 I (Lv.5): +12.5% | 28 × 1.125 | 31.5 |
| 묵직한 타격 (Lv.4): +27% | 31.5 × 1.27 | 40 |
| 강철구 II (Lv.5): ×1.08 | 40 × 1.08 | 43.2 |
| 관성 돌파 I (Lv.5): ×1.35 (고속) | 43.2 × 1.35 | 58.3 |
| 플리퍼 스매시 (Lv.3): ×1.45 | 58.3 × 1.45 | 84.5 |
| 크리티컬 (확률 35%): ×1.8 | 84.5 × 1.8 | **152.1** |
| DEF 20% 적용 | 152.1 × 0.8 | **121.7** |
| 분노의 일격 (HP≤30%): +22.5% | 121.7 × 1.225 | **149.1** |

> **초당 DPS 추산**: 초당 평균 타격 2.5회 × 149.1 × (크리티컬 확률 가중) ≈ **초당 ~320**
> → 겨울여왕 HP 56,000 / 320 ≈ **175초** → 180초 제한 시간 내 클리어 가능 ✅

## 4. 원소(마법) 데미지 별도 계산

원소 스킬의 데미지는 물리와 별도로 계산됩니다.

```
ElementalDamage = SkillBaseDamage * (1 + PlayerLevel * 0.015) * SkillLevelBonus
                  * MaterialBonus(미스릴: ×1.15)
                  * RuneBonus(조건부)
                  - MRes 감소
```

### 상태이상 도트 데미지
- **화상**: 초당 `기본 공격력의 5% + (스킬Lv * 1%)`, 최대 중첩 수에 따라 합산
- **빙결 둔화**: 데미지 없음, 이동/공격 속도 감소
- **감전**: 5% 확률 0.5초 스턴, 데미지 없음

---

## 4-1. 제어 빌드 시뮬레이션 (Lv.90 vs 겨울 여왕)

제어 빌드는 DPS가 낮지만, **시간 회복 + 낙사 방지**로 실질 플레이 시간을 연장합니다.

| 요소 | 수치 |
|---|---|
| 기본 DPS (스킬 트리 투자 적음) | ~150/초 |
| 시간 회복 (크로노 코어 Lv.5 + 타임 브레이커) | 최대 +60초 |
| 에너지 실드 + 퍼펙트 디펜스 | 낙사 페널티 대폭 감소 |
| 실효 전투 시간 | 180초 + 60초(회복) = **240초** |

> 겨울여왕 HP 56,000 / 150 DPS = **373초** → 240초로는 부족?
> **보완**: 리바운드 실드(보스 투사체 반사 데미지, Lv.3: 190%) + 타임 딜레이전(슬로우 중 정밀 타격)으로 실질 DPS ~240까지 상승
> 56,000 / 240 ≈ **233초** → 240초 범위 안에서 **A~B등급 클리어 가능** ✅

### 결론: 제어 빌드는 "생존으로 버티며 안정적으로 클리어"하는 설계 의도에 부합

---

## 4-2. 원소 빌드 시뮬레이션 (Lv.90 vs 겨울 여왕)

원소 빌드는 **멀티볼 + 도트 데미지 + 속성 폭발**로 DPS를 확보합니다.

| 요소 | 수치 |
|---|---|
| 기본 물리 DPS (투자 적음) | ~100/초 |
| 멀티볼 II (공 3개, Lv.3): 타격 횟수 ×3, **각 공 80% 데미지** | 물리 DPS ×2.4 = ~240/초 |
| 화상 도트 (파이어볼 I Lv.5, 4중첩) | 초당 ~40 추가 |
| 속성 융합 폭발 (멀티볼 충돌 시) | 폭발당 ~80 |
| 미스릴 공 마법 증폭 ×1.15 | 마법 데미지 전체 +15% |
| 겨울 여왕 MRes (DEF 20%의 50% = 10%) | 마법 데미지 ×0.9 |
| **총 추산 DPS** | **~310/초** |

> 겨울여왕 HP 56,000 / 310 DPS ≈ **181초** → 180초 제한 내 **A등급 가능, 마나 관리 우수 시 S등급** ✅
> 단, 멀티볼 유지를 위한 마나 관리가 핵심. 마나 부족 시 DPS 급감.

### 결론: 원소 빌드는 "마나 관리 성공 시 높은 DPS"로 하이리스크-하이리턴, 파괴 빌드와 경쟁 수준

---

## 4-3. 빌드별 밸런스 요약

| 빌드 | 추산 DPS | 클리어 시간 | 예상 등급 | 난이도 | 핵심 전략 |
|---|---|---|---|---|---|
| 🔴 **파괴** | ~320 | ~175초 | A~S | ★★★ | 콤보+크리티컬 극대화 |
| 🟢 **제어** | ~240 | ~233초 | B~A | ★★ | 시간 회복+반사 데미지로 연장 |
| 🔵 **원소** | ~310 | ~181초 | A~S | ★★★★ | 멀티볼(80% 데미지)+마나 관리 |

> 3개 빌드의 DPS가 310~320 범위로 수렴하여, 빌드 간 밸런스가 대폭 개선되었습니다. 제어 빌드는 DPS 대신 생존력으로 차별화되고, 원소와 파괴는 비슷한 DPS에 다른 조작 난이도로 경쟁합니다.
